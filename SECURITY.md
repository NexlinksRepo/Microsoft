# Security policy

## Sensitive evidence

The projects in this repository can collect Microsoft tenant, user, device, policy, application,
IP address, location and identity-risk data.

Do not commit or attach generated output, raw Graph responses, JSONL exports, local configuration,
certificates, private keys, secrets, tokens or tenant screenshots to a public issue or pull request.
Use synthetic data for tests and reproductions.

Repository ignore rules cover the standard output and credential paths, but contributors must review
staged changes before publishing.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use the repository's private GitHub
Security Advisory feature when available, or contact the repository owner privately. Include the
affected project/version, synthetic reproduction steps, impact and proposed mitigation.
