# Microsoft tools

Practical Microsoft administration tools by Phil Kinsley.

| Tool | Purpose |
| --- | --- |
| [Intune Endpoint Readiness Collector](Intune/IntuneReadinessCollector/) | Collect Microsoft Graph evidence for an Intune readiness review. |

The collector gathers evidence and creates JSON for a separate scoring and reporting workflow. It does not change tenant configuration or assign readiness scores.

Start with the [collector README](Intune/IntuneReadinessCollector/README.md) for requirements, permissions, examples, and privacy details. See [how the code works](Intune/IntuneReadinessCollector/HOW-IT-WORKS.md) for a walkthrough.
